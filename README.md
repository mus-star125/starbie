# starbie

I made a starbie keychian - thats a bit vague. Basically a simpler version of the popular "starboy" keychain. its the first project we made in half-life and the first hardware - project I have ever made!

Before I even got to the instructions i ran into my first problem: downloading KiCad. Now this step is really easy on windows or mac but unfortunately I don't have those and had to use my chrome book. The process of downloading KiCad on Chromebook is different and was completely new to me. I had to start by installing Linux - which is a tiny computer in my computer- I assigned it about 10GB and had to code- download KiCad using terminal  - which is according to google: "a command-line interface application used to run text-based commands, access a Linux development environment, or perform system diagnostics."- After about an hour of trying to figure the code out i finally got it to install but then i realised 10GB was not enough so I moved it up to 25GB (That work wayy better)
